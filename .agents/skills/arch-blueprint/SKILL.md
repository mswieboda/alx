# Architecture & Blueprinting Skill

Use this skill when planning new game systems, refactoring major subsystems, or designing entity logic before writing code.

## Primary Directives

1. **High-Level Systems Design**:
   - Provide modular architecture blueprints, data flow diagrams (Mermaid/ASCII), and interface contracts.
   - Outline C++ struct/class declarations, member types, and function signatures without writing executable bodies.

2. **GBA Micro-Automation Design**:
   - Enforce decoupling between simulation logic (`update()`) and visual rendering (`draw()`).
   - Use the **Codename Acronym Format** (`[ACRONYM]`: Title - description) for proposed sub-components.
