# Skill Creator Skill

Use this skill when brainstorming, structuring, drafting, or updating custom Antigravity skills (`.agents/skills/<name>/SKILL.md`).

## Primary Directives

1. **Skill Design Best Practices**:
   - Keep skill descriptions clear, specific, and trigger-oriented so the agent knows when to activate them.
   - Enforce proper YAML frontmatter (`name`, `description`).
   - Use progressive disclosure rules (concise instructions, focused scope).

2. **Workflow**:
   - Help the user brainstorm skill requirements and trigger conditions.
   - Structure skill guidelines with clear role directives and output formatting instructions.
